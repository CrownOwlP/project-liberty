## Reading the two lines that mislead most

**"Durable journal: no (local checkout only)"** is not a defect and was never one. It reports
whether `LIBERTY_JOURNAL_DIR` is set in the process that generated the page. Both agent workflows
set it to `coordination/agent-bus/cloud-journal`, so a hosted run reports `yes (cloud mode)`. This
snapshot says `no` because it was generated locally — which is the same fact as `Run: local`, said
twice.

**"Quarantined messages: None"** was true when this snapshot was taken. It is no longer: three
`review_request` messages are now quarantined in `coordination/agent-bus/rejections/`. A
regeneration will list them.
